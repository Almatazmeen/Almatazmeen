## 🚀 Featured Projects

### 🧠 Skilligy — AI Interview Practice Platform

An AI-powered interview practice platform that simulates **text, voice,
and video interviews** and provides personalized performance feedback.

**Key Features**

- 📄 Resume analysis and skill extraction
- 💬 AI-generated role-specific interview questions
- 🎙️ Voice interview with speech-to-text
- 📊 Speaking rate, filler-word and pause analysis
- 🎥 Video interview with face and engagement analysis
- 🤖 LLM-based answer evaluation
- 📈 Final interview performance analysis

**Built with:**  
`Python` `FastAPI` `Whisper` `OpenCV` `MediaPipe` `LLM APIs`

---

### 📦 ShipmentSure — Intelligent Shipment Delay Prediction

A machine-learning based logistics prediction system designed to predict
whether shipments are likely to arrive on time.

**Key Features**

- 📊 Data preprocessing and feature engineering
- ⚖️ Class imbalance handling using SMOTE
- 🤖 Multiple ML model comparison
- 📈 Model evaluation using accuracy and ROC-AUC
- 🔍 SHAP-based model explainability
- 🌐 Backend integration for predictions

**Built with:**  
`Python` `Scikit-Learn` `XGBoost` `Pandas` `SHAP` `Flask` `SQLite`

conversational travel assistant and receive travel-related guidance.
